1.java的运行过程是怎么样的？
答：先有一个Java文件给人看，再有一个class文件给机器看（机器看不懂Java文件），运行的时候需要虚拟机（编程语言编辑器在下载后里面就有，就像跨平台模拟器），运行的是class文件

2.Java是直接运行在操作系统里面的吗？
答：不是，是在虚拟机里面运行，就像手机游戏需要借助模拟器才能在电脑上玩

3.虚拟机的好处是什么？
答（不太确定）：很灵活，不局限于本地设备，增加跨平台性
✨ 精修补充：

一次编写，到处运行（Write Once, Run Anywhere）：这是最核心的。

内存管理（垃圾回收，GC）：JVM 会自动帮你清理不用的内存，不用像 C/C++ 那样手动 free，极大地降低了内存泄漏的风险。

即时编译（JIT）：JVM 会在运行时把热点代码（频繁执行的代码）直接编译成机器码，跑得越来越快。

安全沙箱：JVM 限制了 Java 代码不能直接访问操作系统的底层，防止恶意代码破坏系统。



4.为什么要跨平台？
答（不太确定）：打破本地限制，增强环境适应性
✨ 精修补充（从“开发者/企业”的角度）：

降低开发成本：以前用 C/C++，你要给 Windows 写一套代码，给 Mac 写一套代码，给 Linux 再写一套。有了 Java，你只写一次，就能在任何装了 JVM 的系统上跑。

适应服务器环境：现在企业服务器大多用 Linux，但程序员开发用的是 Windows/Mac。跨平台特性让代码在 Windows 上写，直接部署到 Linux 服务器上，丝滑过渡。
