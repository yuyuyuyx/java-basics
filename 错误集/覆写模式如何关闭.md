# VS Code 关闭覆写模式（Overwrite Mode）指南

在 VS Code 中打字时，如果发现新输入的字符会覆盖掉后面的字符，说明不小心进入了“覆写模式”。以下是关闭和防止误触的几种方法。

## ⌨️ 方法一：按 Insert 键（最快）
直接按一下键盘上的 `Insert` 键（有些键盘缩写为 `Ins`），就能在“插入模式”和“覆写模式”之间切换回来。
* **如果键盘没有 Insert 键**：可以试试 `Ctrl + Shift + I`（Windows/Linux）或 `Cmd + Shift + I`（Mac）。
* **状态确认**：查看 VS Code 窗口右下角的状态栏。如果显示 `OVR`，说明处于覆写模式；显示 `INS` 或没有提示，则是正常的插入模式。

## ⚙️ 方法二：修改设置，防止误触（推荐）
如果你担心以后不小心再按到 `Insert` 键，可以修改设置让这个键失效：
1. 按 `Ctrl + Shift + P` 打开命令面板。
2. 输入 `Preferences: Open Keyboard Shortcuts (JSON)` 并选择它。
3. 在打开的 `keybindings.json` 文件中，添加以下内容并保存：
   ```json
   {
       "key": "insert",
       "command": "-editor.action.toggleOvertypeInsertMode"
   }
