## Java 基础知识要点

### 核心概念

- **基础语法**：变量、数据类型、运算符
- **面向对象**：类、对象、继承、封装、多态
- **异常处理**：try-catch-finally、异常类型
- **集合框架**：List、Set、Map 等常用集合
- **IO 流**：文件读写、输入输出操作
- **多线程**：线程创建、同步、并发控制

## 使用说明

### 环境要求
- JDK 8 或更高版本
- Maven 或 Gradle 构建工具

### 运行方式
```bash
# 编译项目
javac *.java

# 运行主类
java MainClassName
```
