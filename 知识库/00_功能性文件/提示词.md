# 🤖 AI 提示词库（统合版）

> 使用方法：找到对应的场景，复制下方的文字，替换掉【】里的内容，直接发给 Deep Copilot。

---

## 📥 场景一：单篇笔记归档（写完立刻用）
**替换变量**：【笔记文件名】

读取文件 `01_收件箱/【笔记文件名】.md`。请执行以下操作：
1. 阅读正文内容，推断 2-3 个精准的标签（如 #Java、#算法、#工具），写入 YAML 头部的 tags 字段。
2. 提取正文第一句有实质内容的话，填入 description 字段。
3. 扫描知识库，找出 2-3 篇相关笔记，在文末 `## 相关链接` 处补充 [[双向链接]]。
4. 完成后将内容写回文件。不要修改正文核心内容。

---

## 📦 场景二：批量清理收件箱（定期维护）
**替换变量**：无，直接复制

扫描 `01_收件箱` 下的所有 `.md` 文件。请对尚未归类的笔记执行以下操作：
1. 阅读正文，补全 YAML 头部的 tags 和 description。
2. 基于标签，将它们移动到合适的分类文件夹（如 `02_Java笔记`、`03_开发工具`）。如果文件夹不存在，请新建。
3. 更新 `00_功能性文件/索引.md`，按标签分组列出这些笔记的 [[链接]]。
4. 注意：一次最多处理 5 篇笔记。处理完这批后等我确认，再继续下一批。不要合并任何笔记。

---

## 🔗 场景三：构建知识图谱（梳理关联）
**替换变量**：【目标文件夹名】

读取 `【目标文件夹名】` 文件夹下的所有笔记。分析笔记之间的概念关联（例如 [[二分查找]] 属于 [[数组算法]]，[[面向对象]] 包含 [[封装]]）。在每篇笔记末尾的 `## 相关链接` 处，补充指向其他相关笔记的 [[链接]]。不要修改正文核心内容，只补充链接。

---

## 💻 场景四：代码转笔记（沉淀经验）
**替换变量**：【文件夹名】、【文件名】

读取文件 `学习草稿/【文件夹名】/【文件名】.java`。请忽略具体的测试数据（如 33, 5, 22），只提取：
1. 这段代码解决的核心问题。
2. 核心算法思想或实现思路。
3. 通用代码模板（请用 Java 代码块包裹）。
请将这些内容写成一封 Markdown 笔记，存入 `01_收件箱`，自动打上 #Java、#数组 等标签，在 description 中写明一句话总结。

---

## 🔍 场景五：索引自动体检（查漏补缺）
**替换变量**：无，直接复制

对比 `01_收件箱` 和 `00_功能性文件/索引.md`。找出所有尚未被收录进索引的笔记。检查它们的 tags 是否缺失，如果缺失则自动补全。然后将这些笔记按标签分类，补充到 `索引.md` 的对应分组下。
