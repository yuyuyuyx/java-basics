# VS Code (WSL) 快速手写 Java 自定义行为方法记录

## 一、 适用场景
在同一个类中，需要自定义行为方法时（例如面向对象练习中给 `dog` 类写 `bark()`、`run()` 等方法）。
**注意**：VS Code 没有一键生成任意自定义方法的快捷键，但可以利用代码片段（Snippet）和智能补全快速敲出。

## 二、 快速生成方法骨架的方法

### 1. 使用 `method` 代码片段
- 在类内部输入 `method`。
- 按下 `Tab` 键，会自动生成一个方法骨架。
- 随后依次输入：
  - 修饰符（如 `public`） -> 按 `Tab`
  - 返回值类型（如 `void`） -> 按 `Tab`
  - 方法名（如 `bark`） -> 按 `Enter`
- 大括号 `{ }` 会自动生成，光标会停留在方法体内部。

### 2. 纯手动快速输入（最常用）
直接输入方法签名，利用编辑器的自动补全和括号自动闭合功能：
- 输入：`public void bark()` 
- 按下 `Enter`（或 `Tab` 补全），VS Code 会自动帮你补全大括号 `{ }`。
- 示例：
  ```java
  public void bark() {
      // 光标自动定位在这里，直接写方法体
      System.out.println("汪汪汪");
  }
